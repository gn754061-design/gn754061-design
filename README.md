Software developer specializing in retro game localization, font pipelines, RTL text shapers, and reverse engineering tooling for classic gaming consoles.

### ⚙️ المهارات والتقنيات / Technical Highlights

- **RTL Shaping & Joining:** بناء محركات تشكيل وربط الحروف العربية من الصفر للأجهزة ذات الموارد المحدودة.
- **Font Rasterization & Tile Mapping:** تحويل خطوط البكسل إلى صيغ البلاطات الثنائية الأصلية (8-bpp / 4-bpp) وحساب جداول العرض (Width Tables).
- **Automated QA & Emulation:** أتمتة اختبارات الحوارات والتقاط الشاشات التحققية عبر المحاكيات.
- **Legal & Clean Distribution:** التزام تام بعدم توزيع ملفات ROM/ISO المحمية، والاعتماد حصراً على أدوات مفتوحة ورقع فروقية (BPS).
